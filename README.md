# CALCULADORA-EM-PYTHON-

Atividade desenvolvida para a disciplina de Engenharia de Software do curso de Análise e Desenvolvimento de Sistemas do IFCE - Campus Tauá.

DESCRIÇÃO
Esta aplicação implementa uma calculadora simples que realiza as seguintes operações:

- Soma
- Subtração
- Multiplicação
- Divisão

TECNOLOGIAS UTILIZADAS
- Python
- Git
- GitHub

COMO EXECUTAR
1. Clone o repositório
2. Execute o arquivo CALCULADORA_IF_ELIF.py e CALCULADORA_MATCH_CASE.py.
